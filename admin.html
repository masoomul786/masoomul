🌐 GitHub Pages — How to Publish Changes

  1. Every time you press Save, a data.js file is auto-downloaded.
  2. Go to your GitHub repo → click data.js.
  3. Click the ✏️ pencil (Edit) icon → select all → paste the downloaded file.
  4. Click "Commit changes" → GitHub Pages rebuilds in ~30 seconds.
  5. Changes are now live for all visitors! 🎉
